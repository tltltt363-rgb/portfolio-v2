# 방송용 아바타 포트폴리오

사이트 주소: https://tltltt363-rgb.github.io/portfolio-v2/

글자, 가격, 사진 목록은 거의 다 **`config.js` 파일 하나**에서 고쳐요.
고친 뒤 1~2분 지나서 사이트를 새로고침하면 바로 보여요. (숫자 올리기 같은 건 필요 없어요)

---

## 0. 가장 쉬운 방법: 편집기 (사진 보면서 고치기)

**편집기 주소: https://tltltt363-rgb.github.io/portfolio-v2/editor.html**

코드를 안 보고, 사진과 입력 칸으로 고칠 수 있어요. 휴대폰에서도 돼요.
왼쪽에서 고치면 **오른쪽 미리보기(실제 사이트 모습)가 바로 바뀌어요.** 미리보기에서 칸을 누르면 그 칸을 고치는 곳으로 이동해요. (휴대폰은 위쪽 **미리보기** 버튼)
미리보기는 저장 전 모습이에요. 다른 사람에게 보이려면 **저장하기**를 눌러야 해요.

**처음 한 번만: GitHub 연결**

1. 편집기 오른쪽 위 **GitHub 연결** 을 눌러요.
2. 안내에 나온 링크로 들어가 **연결 키(토큰)** 를 만들어요.
   - Repository access: `Only select repositories` → `portfolio-v2`
   - Permissions → Repository permissions → **Contents: Read and write**
3. 만든 키(`github_pat_`로 시작)를 붙여넣고 **연결하기**.

> 연결 키는 그 브라우저에만 저장돼요. 채팅이나 다른 사람에게 보내지 마세요.
> 다른 기기(휴대폰 등)에서 쓰려면 그 기기에서 한 번 더 연결하면 돼요.

**고치는 법**

- 위쪽 탭(기본 · 작업물 · 가격 · 아바타 · 진행·주의사항)을 골라 칸을 고쳐요.
- 목록은 ↑ ↓ 로 순서, ⧉ 로 복사해서 추가, ✕ 로 삭제해요.
- **작업물** 탭: 사진 아래에 제목·설명을 적고, ◀ ▶ 로 순서를 바꿔요.
  **사진·영상 추가** 를 누르거나 끌어다 놓으면, 사진은 자동으로 알맞은 크기(webp)로 바뀌어 올라가요.
- **비포·애프터** 탭: 카테고리를 고르고 **+ 사례 추가** → BEFORE / AFTER 칸을 눌러 사진을 넣고 제목·설명·작업 기간·플랫폼을 적어요.
  사례를 하나라도 넣으면 사이트의 임시 칸은 사라지고, 사례가 없는 카테고리는 숨겨져요.
- 다 고쳤으면 오른쪽 위 **저장하기** (컴퓨터는 `Ctrl + S`). 1~2분 뒤 사이트에 반영돼요.

## 1. 글자·가격 고치기

1. 저장소에서 **`config.js`** 를 눌러 열어요.
2. 오른쪽 위 **연필(✏️)** 버튼을 눌러요.
3. 값을 고쳐요.
4. 오른쪽 위 초록색 **Commit changes...** → 창이 뜨면 다시 **Commit changes** 를 눌러요.
5. 1~2분 뒤 사이트를 새로고침해요.

> 휴대폰에서도 같은 방법으로 고칠 수 있어요. (GitHub 앱이나 모바일 웹)

### 적는 규칙

| 무엇 | 이렇게 | 예 |
|---|---|---|
| 글자 | 따옴표 안에 | `"기본 성형 세트"` |
| 숫자(가격) | 따옴표 없이, 쉼표 없이 | `380000` |
| 켜기 / 끄기 | `true` / `false` | `saleReady: true,` |
| 줄 바꿈 | `//` 넣기 | `"방송 화면에서 // 더 빛나는 아바타로"` |
| 강조(주의사항) | 별표 두 개로 감싸기 | `"보관 기간은 **한 달**입니다."` |

- 줄 끝의 **쉼표(,)** 는 지우지 마세요.
- `//` 뒤에 적힌 설명은 화면에 안 나와요.

### 목록 고치기 (작업물, 세트, 개별 작업, 장점, 주의사항, 질문 …)

목록은 `[` 와 `]` 사이에 **한 줄이 카드 하나**예요.

```js
items: [
  { group: "성형", name: "성형", desc: "유니티, 블렌더", price: 100000 },
  { group: "성형", name: "원화 기반 성형", desc: "", price: 150000 },
],
```

- **추가**: 한 줄을 복사해서 바로 아래에 붙여넣고 내용을 바꿔요.
- **삭제**: 그 줄을 지워요.
- **순서 바꾸기**: 줄을 위아래로 옮기면 화면 순서도 바뀌어요.
- 개수(Count)를 따로 적을 필요가 없어요. 줄 수만큼 자동으로 나와요.

## 2. 작업물 사진·영상 올리기

1. 저장소에서 `media` 폴더 → 카테고리 폴더로 들어가요.

   | 카테고리 | 폴더 | config.js 목록 |
   |---|---|---|
   | 성형 | `media/seonghyeong` | `worksA` |
   | 페이셜 | `media/facial` | `worksB` |
   | 텍스쳐 | `media/texture` | `worksC` |
   | 뽀잉눈 | `media/boing` | `worksD` |

2. 오른쪽 위 **Add file → Upload files** 를 눌러 파일을 끌어다 놓고 **Commit changes** 를 눌러요.
3. `config.js` 의 해당 목록에 한 줄을 추가해요. **파일 이름만** 적으면 돼요.

```js
worksA: [
  { file: "seonghyeong-32.webp", title: "Milltina", desc: "성형" },
  ...
],
```

- `.mp4` `.webm` `.mov` 는 영상(자동 재생), 나머지는 사진으로 나와요.
- 파일 이름에 **띄어쓰기·한글·괄호는 피해** 주세요. (예: `seonghyeong-32.webp` 처럼)
- 사진은 너무 크면 느려져요. 2000px 이하, 한 장 1MB 안쪽이 좋아요.
- 사진을 빼고 싶으면 목록에서 그 줄만 지우면 돼요. (파일은 남아 있어도 괜찮아요)

## 3. 자주 하는 일 바로 찾기

| 하고 싶은 일 | config.js 에서 찾을 이름 |
|---|---|
| 브랜드 이름 넣기 | `brandName` |
| 맨 위 제목·설명 | `heroTitle`, `heroDesc` |
| 장점 카드 | `strengths` |
| 비포·애프터 사례 | `baA` ~ `baD` (사진은 `media/before-after`) |
| 작업물 사진·제목 | `worksA` ~ `worksD` |
| 판매(BOOTH) 링크 버튼 | `worksLinkC` (다른 카테고리는 `worksLinkA` 등) |
| 분양 아바타 열기 / 준비 중 | `saleReady` (`true` / `false`), 목록은 `sales` |
| 보유 아바타 | `avatars` |
| 이벤트 문구 | `eventText` (비우면 배너가 사라져요) |
| 세트 상품 | `sets` |
| 개별 작업과 가격 | `items` |
| 마감 옵션, 수정 비용 | `dl3Pct`, `dl1Pct`, `revisionFree`, `revisionPrice` |
| 진행 과정 | `processSteps`, `processFacts` |
| 주의사항 · 불가능 작업 · 작업 기한 | `notices`, `impossible`, `deadlineText` |
| 자주 묻는 질문 | `faqs` |
| 포인트 색 | `accent` |

## 4. 문제가 생겼을 때

- **사이트가 하얗게 나와요** → `config.js` 에서 따옴표(`"`)나 쉼표(`,`)가 빠졌을 가능성이 커요.
  `config.js` 를 열고 오른쪽 위 **History** 를 누르면 고친 부분이 초록/빨강으로 보여요.
  잘못 고친 곳을 바로잡거나, 이전 버전 내용을 복사해서 되돌리면 돼요.
- **고쳤는데 안 바뀌어요** → 저장 후 1~2분 기다린 뒤 새로고침(`Ctrl + F5`, 휴대폰은 새로고침 두 번) 해 보세요.
  저장소 위쪽 **Actions** 탭에서 초록 체크가 뜨면 반영된 거예요.

## 파일 구성 (참고)

| 파일 | 하는 일 | 고칠 일 |
|---|---|---|
| `config.js` | 글자, 가격, 목록, 사진 파일 이름 | **여기만 고치면 돼요** |
| `media/` | 작업물 사진·영상 | 파일을 올릴 때 |
| `index.html` | 화면 배치와 디자인 | 거의 없어요 |
| `js/portfolio.js` | 계산기, 슬라이드, 크게 보기 같은 동작 | 거의 없어요 |
| `js/dc-runtime.js`, `js/react.bundle.js` | 화면을 그려주는 실행 파일 | 고치지 마세요 |
