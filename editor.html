GitHub 연결하기 (처음 한 번만)

연결하면 고치는 내용(사진 포함)이 자동으로 저장돼요. 그러려면 연결 키(토큰)가 필요해요. 이 키는 이 브라우저에만 저장되고 다른 곳으로 보내지지 않아요. 채팅이나 다른 사람에게는 절대 보내지 마세요.

  1. 여기를 눌러 키 만들기 화면을 열어요. (GitHub 로그인 필요)
  2. Token name: 아무 이름 (예: 포트폴리오 편집기)
  3. Expiration: 원하는 기간 (끝나면 새로 만들면 돼요)
  4. Repository access: Only select repositories → portfolio-v2 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로
  6. 맨 아래 Generate token → 나온 키(github_pat_로 시작)를 복사해서 아래에 붙여넣어요.
