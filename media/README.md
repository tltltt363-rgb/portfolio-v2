# media 폴더

작업물 사진과 영상을 카테고리 폴더에 올려요.

| 폴더 | 카테고리 | config.js 목록 |
|---|---|---|
| `seonghyeong/` | 성형 | `worksA` |
| `facial/` | 페이셜 | `worksB` |
| `texture/` | 텍스쳐 | `worksC` |
| `boing/` | 뽀잉눈 | `worksD` |

올리는 법: 폴더로 들어가서 오른쪽 위 **Add file → Upload files** → 파일 끌어다 놓기 → **Commit changes**

올린 뒤 `config.js` 목록에 파일 이름만 적으면 돼요.

```js
{ file: "seonghyeong-32.webp", title: "Milltina", desc: "성형" },
```

파일 이름은 영어·숫자·하이픈(-)으로 해주세요. (띄어쓰기·한글·괄호는 피해주세요)
